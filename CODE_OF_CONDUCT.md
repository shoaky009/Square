# Code of Conduct

## Our Standard

Contributors and maintainers must communicate respectfully, assume good intent, accept constructive technical feedback, and avoid harassment, discrimination, personal attacks, or disclosure of private information.

## Scope

This standard applies in repository issues, pull requests, discussions, reviews, and other project spaces.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile or the repository's private security reporting channel when privacy is required. Maintainers may edit or remove content, reject contributions, or restrict participation when behavior is harmful or disruptive.

Enforcement decisions should be proportional, documented when appropriate, and focused on maintaining a safe technical community.
