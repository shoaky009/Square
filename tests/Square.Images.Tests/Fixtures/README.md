# Image decoder fixtures

The committed animation fixtures are generated by `tools/ImageFixtureGen` using the repository's deterministic container builders. The same tool invokes ffmpeg/libwebp to regenerate the static lossy VP8 inputs, decodes their normative YUV420 planes, then converts those planes to BGRA with the same deterministic libwebp scalar formula used by Square. Regenerate all fixtures with:

```powershell
dotnet run --project tools/ImageFixtureGen/ImageFixtureGen.csproj -c Release
```

`manifest.json` records each encoded file's SHA-256 and its expected frames. Golden files are headerless, top-down, tightly packed, straight-alpha BGRA (`width * height * 4` bytes). Tests only consume committed files and do not invoke external image tools.

`vp8-manifest.json` records dimensions and SHA-256 for both encoded VP8 files and their raw BGRA goldens. `vp8-alpha-manifest.json` separately identifies static lossy VP8X/ALPH fixtures. Their color channels come from ffmpeg-decoded `yuv420p` planes converted with Square's deterministic scalar formula; alpha comes from the alpha channel of a separate ffmpeg `bgra` decode and is combined without premultiplication. ffmpeg is only required for fixture regeneration, never at test runtime.

`animated-lossy-webp/` contains deterministic lossy WebP animations assembled by the generator from one-frame `libwebp_anim` encodes. The generator owns the `VP8X`, `ANIM`, and `ANMF` muxing so frame rectangles, durations, blend flags, disposal flags, background color, and loop count do not depend on ffmpeg's animation optimization choices. Each composited frame golden uses Square's VP8 YUV-to-BGRA conversion for color, trusted straight alpha extracted from the one-frame WebP decode, and an independent implementation of WebP background, blend, and disposal rules. Active tests validate hashes and container structure, then decode every VP8 and `ALPH+VP8` animation frame and compare the complete composited canvas with its raw BGRA golden. Test execution does not invoke ffmpeg or libwebp.
