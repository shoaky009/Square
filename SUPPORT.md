# Support

Square is experimental and is not recommended for production applications.

- Use GitHub Issues for reproducible bugs and focused feature proposals.
- Include the Square commit/version, operating system, rendering backend, reproduction steps, and relevant logs.
- Use repository discussions, when enabled, for design questions and general usage help.
- Follow `SECURITY.md` for vulnerabilities. Do not disclose them in public issues.

There is no guaranteed response time, compatibility window, or long-term support policy before 1.0.
